## 3. Design Thinking — 10 langkah

### (1) Shapes
```
Scene3D       = { kind: 'field' | 'office', mood, cameraKeys, props[] }
Character3D   = { id, role: 'farmer'|'worker', hat:'caping'|'peci'|'bowl', outfit, blush, mustache }
HookBanner    = { channelPill, lines[3], highlightIndex }
FloatPill     = { text, anchor: Character3D, leader: bool }
Beat          = { id, start, end, scene, cast[], action, grainBaru }
```
Semua ID string lintas-batas wajib tag: `shotId`, `sceneId`, `charId`.

### (2) A dulu — happy path
```
NaskahKenapa (155 kata, 3.2 wps)
  → edge-tts WordBoundary → words.json (timing riil)
    → beats.py → shots.json (9 shot)
      → gh3d.stage field|office (sekali per shot)
        → character3D + props
          → render.mjs (kind:'3d' → three-kit → ffmpeg)
            → audio/mix.py (music + 18 sfx, -14 LUFS)
              → mux → wa-send/*.mp4
```

### (3) Kardinalitas
- Stage 3D: **1 instance per shot**, di-dispose saat shot berganti (cache maks 2 di `player.js`).
- Karakter: 1 hero + 0–2 pendukung per shot.
- Banner: **1 per video** (pinned di shot 1–N).
- Prop titik-cerita: ≥1 per beat.

### (4) E (breakpoints)
| Titik pecah | Perilaku |
|---|---|
| WebGL context hilang | `render.mjs --gl swiftshader` (sudah terverifikasi jalan) |
| Mesh terlalu banyak | instancing (`crowd3D`, rumpun padi) + `flatShading` |
| Teks 3D tidak terbaca | teks **selalu 2D overlay**, bukan `CanvasTexture` di mesh |
| Timing kata meleset | re-align `transcribe.align_script` |

### (5) R (kebutuhan per node)
`three@0.169` + `three/addons` (bloom, output pass), Playwright Chromium, ffmpeg, edge-tts, font Fredoka/Nunito (sudah ada).

### (6) Boundary
Input = naskah + fakta bersumber. Parse di tepi: angka & nama ilmiah **hanya** dari sumber terverifikasi (BBPOPT/Kementan untuk topik sawah).

### (7) Behavior wrap
Retry render per shot; throttle `render_throttled.py`; log ke `build/*.log`. Graph tidak berubah.

### (8) Scope
Stage/geometry/material di-dispose per shot. Render = 1 job berat, background.

### (9) Swap R — verifikasi
Ganti "render penuh" → "2 still per shot" (`--stills`), lihat gambar, baru render penuh.

### (10) A/E terpisah
`draw()` hanya menggambar; error handling di `player.js` (menulis `SHOT ERROR` + frame teks merah) dan runner python.

## 4. Resep visual yang dikunci (untuk skill)

**Field (JadiBegini):**
1. Langit gradien 3-stop (biru → putih → horizons), matahari rendah, fog 25–70.
2. Air sawah = plane `MeshStandardMaterial` roughness 0.12 metalness 0.35 (pantulan langit) di `y=0.02`.
3. Pematang = box tanah `#4a3f2a`, lebar 0.5 m, grid.
4. Rumpun padi = `InstancedMesh` cone hijau `#4e7a2e` tinggi 0.55 m, 3 baris per petak.
5. Kelapa 3D + gubuk + tiang listrik untuk 3 lapis kedalaman.
6. Malam = `night` mood + moon sphere `#eef2ff` + `shaft()` kerucut senter.
7. Grain bar = 0.06.

**Office (TheOfficeExplainer):**
1. Lantai parket `tiles()`, dinding `#2a2238`, partisi kubikel 1.2 m.
2. Meja kayu 2.2×0.08×1.1 di depan karakter, dokumen kertas (plane putih dengan garis), kotak pensil.
3. Jendela `windowPane` besar 6×3.4 dengan interior skyline; sinar `shaft` miring.
4. Moncong spotlight dari atas-kanan, bayangan keras.
5. Pill emas melayang: 2D overlay, jarak 60 px di atas kepala hasil proyeksi kamera.

## 5. Risiko yang sudah terukur
- Render WebGL software: ~1,4–2 fps (dari uji `examples/reaction-time` 3D shot) → video 50 s (±1.200 frame) ≈ **10–14 menit**. Lebih lambat dari 2D (7 fps).
- Font: `Fredoka`/`Nunito` belum punya weight 900 penuh; banner memakai 800 + stroke tebal agar tetap "chunky".
- Belum ada aset GLB; semua prosedural (deterministik, tanpa file eksternal).
